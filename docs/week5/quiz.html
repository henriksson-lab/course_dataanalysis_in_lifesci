Week 5 self-check — reproduce and transfer

Use these questions to check the whole workflow and locate any unfinished practical skills. They are not a graded test. Remote tasks requiring an account remain pending until the actual course service is provided.

1. Name the location, not just the filename

Your report rendered remotely, but local Downloads is empty. What should you check? Does closing the SSH terminal necessarily delete saved remote output?

Answer

Locate the output on the remote computer, then check whether it was transferred and to which destination. A remote desktop is not automatic synchronisation. Closing SSH ends a session, not saved files, subject to the service’s storage policy. Do not assume a running process will continue after disconnecting.

2. Count the represented thing

dna <- readLines("data/dna.txt") reads one invented 40-letter line. What are length(dna) and nchar(dna)? Why do they differ?

Answer

length(dna) is 1 stored string; nchar(dna) is 40 characters in that string. Counting vector elements and counting characters answer different questions. The final newline in the file is not another DNA base.

3. Pixels are positions, not plants

The teaching image has 64 pixels, 24 above intensity 100. What fraction is bright? Does that make 64 independent biological replicates or identify one cell?

Answer

The fraction is 24/64 = 0.375. Pixels are related positions in one artificial image. Their count does not establish independent treatment replication or biological identity. Interpretation needs acquisition context, scale, and validation. The threshold count alone does not establish a cell’s area in mm².

4. Available duckweed measurements

Twenty independent flasks were started, ten per allocation. Nutrient flask F17 spilled before weighing. How many available biomass observations are there, and why is replacing the missing value by zero inappropriate?

Answer

There are 10 control and 9 nutrient observations, 19 in total. Zero would invent a known biomass; unavailable and absent biomass are different meanings. Retain the original row, report the loss, and make the comparison conditional on the observed data and missingness limitation.

5. A percentage difference needs its units

In the supplied alternative, percentage yield is 100 × collected mass / supplied maximum mass, with matching mass units. Protocol means are 68.67% and 77.00%. Is their difference an 8.33% relative increase? Does it establish greater purity?

Answer

The modified-minus-standard difference is 8.33 percentage points. A relative percentage change would divide by the starting mean and multiply by 100; it is a different quantity. Greater yield alone does not establish greater purity, safety, sustainability, or general superiority. Product purity was an explicit simplifying assumption in this numerical exercise, not a measured finding.

6. Share a recipe, not only its output

A peer receives your HTML but cannot update the analysis for new data. What else should be in the shared project? Why test extraction in a new location?

Answer

Include the .Rmd source, actual input CSV, dictionary, project file, required output folder if used, and a short README naming packages and the file to render. Testing a new location detects dependencies on personal absolute paths or missing files. The .Rproj does not contain the dataset. A fresh session detects hidden interactive objects. Do not include credentials or unrelated personal work.

7. What does successful reproduction establish?

The peer renders your source successfully from the shared input. Does that prove the experimental design and interpretation are correct, or provide a backup against losing your only disk?

Answer

It establishes that the supplied work regenerates the result in the tested environment. A flawed analysis can be reproducible. Scientific validity still needs the design, assumptions, checks, and reasoning. Backup is a separate action: keep a retrievable copy using supported separate storage.

8. Checks have limits

The received table has the same filename, byte size, row count, and column names as the source. Does this prove that every measurement matches? What would you check in a small transfer audit before making a stronger claim?

Answer

No. A changed value can occupy the same number of characters, and tables can have identical dimensions but different contents. Inspect the intended saved input, verify named records and missing values, and compare the contents using the supported method. Record the actual source and destination locations. Do not confuse an unsaved editor change with the bytes that were sent.

9. One changed label, one unchanged length

The invented DNA string has A11, C9, G9, T11. Its first A is replaced by G in a new object. What are the changed A/G counts, total length, and GC fraction, defined here as (G + C) / all letters? Did the original file necessarily change?

Answer and calculation

A10 and G10, still 40 letters, with GC fraction (10 + 9) / 40 = 0.475. The original fraction was 18 / 40 = 0.45. Changing a new R object does not write a file unless a save/write operation is performed. A count-based fraction does not establish what a DNA sequence does biologically.

10. A threshold can change its answer without moving an object

The toy image has 24 pixels at 210 and 40 at 25. Add 30 to every intensity in a new object. Compare counts above 220 before and after. What about counts above 100? Explain the difference between > 210 and >= 210 in the original.

Answer

Above 220 changes from zero to 24 because the bright pixels become 240. Above 100 stays at 24. Original > 210 excludes equality and selects zero, whereas >= 210 selects 24. Matrix positions did not change, so a threshold-count change alone cannot establish a larger organism or a change in physical object area.

11. A fresh dataset requires fresh counts

The algae table has 24 independent cultures, twelve per allocation. A19 in the supplement group spilled before weighing. Its available group means are 28.20 mg for reference and 33.91818 mg for supplement. Give available n and the observed supplement-minus-reference difference. Must supplement contain the largest single observation?

Answer and calculation

Available n is 12 reference and 11 supplement, 23 in total. The directed difference is 33.91818 - 28.20 ≈ 5.72 mg. A higher group mean does not require every value to be higher: reference culture A11 at 41.7 mg is the largest individual observation. Describe both the centre and observations.

12. A sensitivity check does not justify deletion

Omitting A11 lowers the algae reference mean to 26.97273 mg and increases the observed difference to about 6.95 mg. No source record identifies A11 as an error. Which result should be primary, and how should the other be labelled?

Answer

Keep the all-available-measurements result primary: about 5.72 mg. The other is a diagnostic sensitivity calculation with an explicitly changed sample and no independent evidence for exclusion. Reweighing preferences or a more convenient p-value cannot justify removing a recorded observation. A19 remains a distinct missing measurement; omitting A11 does not repair that loss.

13. Rendering can miss the more serious fault

In a disposable report copy, an input is temporarily renamed. In another copy, the prose claims that every enrolled duckweed flask had a measured outcome. Which fault should stop rendering, and which may render successfully?

Answer

The unchanged input path should fail when its required file is unavailable. Restore its exact name/path, rerun, and compare the result. The false prose can render successfully because software does not automatically validate the claim. It contradicts the documented missing F17 measurement. Check scientific meaning as well as execution; keep intentionally faulty copies out of the final package.

14. Is this a rounding difference or a different analysis?

One memo gives a mean of 33.91818 mg and the report displays 33.92 mg. Another report gives 34.32 mg. What should be investigated, and why should you check the input and calculation before changing display precision?

Answer

33.92 is the first value rounded to two decimal places. 34.32 is not explained by that rounding. Check the saved input, available counts, group selection, outcome definition, and calculation, then confirm which rendered file was opened. Changing the number of displayed digits cannot repair a different input or an unrecorded exclusion. Retain full-precision values for subsequent calculations.
