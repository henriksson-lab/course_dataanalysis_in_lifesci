Data Analysis in Life Sciences

One question, one report

Complete one selected study; both use the workflow already practised.

The default duckweed exercise includes a guided Welch comparison. The organic alternative is descriptive and does not require a new test or chemistry knowledge. Week 4’s statistical work remains part of the course in either pathway.

Decide what is independent

The number of rows must be interpreted through the experimental design.

Twenty duckweed flasks were independently allocated nutrients or control. The organic table has twelve independent runs allocated a collection protocol. Many fronds in a flask or repeated weighings of one run do not add independently treated units. Students should state this before calculation.

A missing measurement is not zero

Retain the raw record. State 10 control + 9 nutrient available measurements.

The supplied source record explains F17. We do not know its biomass. A zero would invent a very small biomass and change the comparison. Keep counts of started units and available outcomes distinct.

Import and check before analysing

Check IDs, labels, types, units, missing values, and plausible ranges.

Run from the extracted course project root. All report prerequisites must be in its code. The available object makes the exclusion explicit without overwriting the raw table. No other value is confirmed as an error.

Show observations before a test

Each dot is one flask; diamonds are means. Explain overlap and variation.

This plot uses the actual teaching CSV. It excludes only the unavailable F17 y-value and the caption in the report should say so. A lower control value does not automatically justify exclusion. Group means are not new observations.

State the comparison direction

nutrient <- available |> filter(treatment == "nutrient")
control <- available |> filter(treatment == "control")
comparison <- t.test(nutrient$biomass_mg, control$biomass_mg)

Nutrient minus control: about 7.35 mg, 95% CI 2.27 to 12.44 mg.

Report sample sizes and assumptions, not only the p-value.

The supplied data give Welch p about 0.00723. The interval concerns the mean difference, not 95% of flasks. The inference remains conditional on independence, the distributional assumptions, and the missing-outcome limitation. Students need not derive the test or choose an alternative method catalogue.

Organic alternative: the maximum is given

Yield (%) = 100 × collected mass (g) / supplied maximum mass (g).

Define theoretical mass as the supplied maximum and isolated mass as collected dry product. Purity is assumed solely for this simplified calculation, not measured. Other runs start at different scales, making raw masses incomparable as yield without normalisation.

Compare percentages across independent runs

Describe means, SD, and overlap. No new test is required for this alternative.

Six runs per group, no missing outcomes. Means 68.67% and 77%; SDs 4.32 and 3.74 percentage points. The observed mean difference is 8.33 percentage points, not an 8.33% relative increase. Higher yield alone does not establish purity or general superiority, safety, or sustainability.

Adapt the interpretation to the selected design and outcome.

Students may reuse code patterns, but must change the roles, units, and study interpretation. They should not invent a confidence interval to fill a heading in the descriptive alternative. Neither study needs a new statistical method.

Write a result someone can assess

Include:

  • Direction and size, in the outcome’s units.
  • Numbers of available independent units.
  • Individual variation and the required uncertainty, if estimated.
  • One limitation tied to the design, missing data, or simplified assumptions.

Prompt students to distinguish an observed numerical difference from a universal claim. Simulated teaching data do not establish real biological or chemical effects. Ask which code or table supplies each number in their paragraph.

Keep the whole recipe in the report

  1. Import data and load packages.
  2. Perform checks and calculations.
  3. Produce figures and summaries.
  4. Explain the results and limits.
  5. Save, restart, and render.

The report must not depend on console-only objects. Source files stay in the project root so data/relative paths keep the same meaning. Preserve the input CSV and keep derived output separate.

Start with the claim you intend to support

Write the plan before changing the code.

The analysis plan covers question, unit, outcome, units, missingness, plot and direction. The descriptive organic route stops at a directed observed comparison; the duckweed route adds the taught independent inference. One chosen main study is enough.

Make checks inspectable

For each check, retain operation and finding:

  • Identifiers and allocation labels.
  • Measurement types, units, and unavailable values.
  • Derived outcome and available counts.
  • Comparison direction and interpretation.

“All checks passed” is not enough for another reader. Ask students to show a count or a named record. They can use existing commands rather than a new validation package. One hand calculation helps test the operation’s meaning, but does not by itself validate experimental independence.

Transfer the workflow to a fresh culture study

New file: data/algae.csv; outcome: dry biomass in mg.

Algae are photosynthetic organisms, but the task requires no microbiology: independent cultures were randomly assigned, and one seven-day harvest produced a biomass reading. A19 spilled before weighing. This is a short transfer memo, not a requirement to do both duckweed and organic main reports.

Check before summarising

library(readr)
algae <- read_csv("data/algae.csv", show_col_types = FALSE)
nrow(algae)
anyDuplicated(algae$culture_id)
sum(is.na(algae$biomass_mg))

Expect 24 rows, 0 duplicated IDs, 1 missing measurement.

The available counts are twelve reference and eleven supplement. Keep A19’s raw row and missing value. State that the culture, not its number of cells, is the independent unit. The transfer table has different column and allocation names from the plant table: adapt the roles, not only the title.

Look at the observations before the summary

Which group contains the largest individual observation?

Reference culture A11 has 41.7 mg, larger than every supplement observation. This does not contradict a greater supplement mean. Let students answer the individual-observation question before showing means, so the plot is read as data rather than treated as decoration behind a chosen conclusion.

A group mean is not a rule for every culture

Reference mean ≈ 28.20 mg; supplement mean ≈ 33.92 mg.

The supplement group has the higher mean but its values do not all exceed the reference values. Both individual observations and the summary are informative. The plot alone does not isolate every possible source of biological variation; the supplied design and assumptions still matter.

Zero would invent a different result

The unavailable value has not become observed information.

The correct available supplement mean is 33.91818 mg. Adding a false zero as a twelfth measurement changes it to 31.09167 mg. This is a demonstration of why the rule matters, not an alternative recommended analysis. Keep the raw missing value and explain the loss rather than choosing a convenient invented number.

Repair claims as carefully as code

Faulty statements to challenge:

  • “All enrolled flasks have measured biomass.”
  • “The group SD is the error in the treatment effect.”
  • “A higher product yield proves greater purity.”

Use the specific data and assumptions in the correction.

Duckweed has nineteen available outcomes out of twenty enrolled flasks. SD is individual spread. Organic purity was assumed for a simplified calculation, not measured by yield. A useful rewrite changes the claim’s meaning, not only its strength from proves to suggests. Students record their corrections.

Give the difference a direction

The observed supplement-minus-reference difference is about 5.72 mg.

Reversing the order changes the sign without altering the underlying observations. In the duckweed test, the order also determines the interval’s direction. For the algae transfer memo no new hypothesis test is required. If a taught test is run, it does not replace the requested descriptive reasoning.

Write a bounded result paragraph

Include unit, available n, direction, spread or overlap, and a limitation.

A larger mean does not imply every treated observation is larger.

The algae memo includes a saved summary and figure. Calculate with unrounded means and report A19’s loss. Interpret this simulated study within its design and assumptions.
