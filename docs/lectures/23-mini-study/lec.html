The default duckweed exercise includes a guided Welch comparison. The organic alternative is descriptive and does not require a new test or chemistry knowledge. Week 4’s statistical work remains part of the course in either pathway.

Decide what is independent

The number of rows must be interpreted through the experimental design.

Twenty duckweed flasks were independently allocated nutrients or control. The organic table has twelve independent runs allocated a collection protocol. Many fronds in a flask or repeated weighings of one run do not add independently treated units. Students should state this before calculation.

A missing measurement is not zero

Retain the raw record. State 10 control + 9 nutrient available measurements.

The supplied source record explains F17. We do not know its biomass. A zero would invent a very small biomass and change the comparison. Keep counts of started units and available outcomes distinct.

Show observations before a test

Each dot is one flask; diamonds are means. Explain overlap and variation.

This plot uses the actual teaching CSV. It excludes only the unavailable F17 y-value and the caption in the report should say so. A lower control value does not automatically justify exclusion. Group means are not new observations.

State the comparison direction

nutrient <- available |> filter(treatment == "nutrient")
control <- available |> filter(treatment == "control")
comparison <- t.test(nutrient$biomass_mg, control$biomass_mg)

Nutrient minus control: about 7.35 mg, 95% CI 2.27 to 12.44 mg.

Report sample sizes and assumptions, not only the p-value.

The supplied data give Welch p about 0.00723. The interval concerns the mean difference, not 95% of flasks. The inference remains conditional on independence, the distributional assumptions, and the missing-outcome limitation. Students need not derive the test or choose an alternative method catalogue.

Organic alternative: the maximum is given

Both masses use grams. No reaction equation or molar-mass lookup is needed.

Define theoretical mass as the supplied maximum and isolated mass as collected dry product. Purity is assumed solely for this simplified calculation, not measured. Other runs start at different scales, making raw masses incomparable as yield without normalisation.

Compare percentages across independent runs

Describe means, SD, and overlap. No new test is required for this alternative.

Six runs per group, no missing outcomes. Means 68.67% and 77%; SDs 4.32 and 3.74 percentage points. The observed mean difference is 8.33 percentage points, not an 8.33% relative increase. Higher yield alone does not establish purity or general superiority, safety, or sustainability.

Do not transfer an old conclusion merely by changing a plot title.

Students may reuse code patterns, but must change the roles, units, and study interpretation. They should not invent a confidence interval to fill a heading in the descriptive alternative. Neither study needs a new statistical method.

Write a result someone can assess

Include:

  • Direction and size, in the outcome’s units.
  • Numbers of available independent units.
  • Individual variation and the required uncertainty, if estimated.
  • One limitation tied to the design, missing data, or simplified assumptions.

Prompt students to distinguish an observed numerical difference from a universal claim. Simulated teaching data do not establish real biological or chemical effects. Ask which code or table supplies each number in their paragraph.

Keep the whole recipe in the report
