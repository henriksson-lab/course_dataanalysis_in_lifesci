Week 1 self-check — files and computers

Try each question before opening its answer. These are practice checks, not graded examination questions. Use your file manager, terminal, and terminal reference to check actions as well as words.

1. Find the saved work

You edited a note in an application, closed it, and cannot find it in the application’s recent-files list. What should you be able to identify, and why does the application name alone not tell you where the file is?

Answer and check

Identify the computer, folder, and filename where the note was saved. An application can open files from many locations. Navigate to the saved folder in the file manager and reopen the ordinary file. If the changes were not saved, the saved contents may differ from the previous screen.

2. A relative path needs a starting place

From introcomputing-course, the path data/seedlings.csv works. From inside reports, why does the same path ask for a different location?

Answer and check

A relative path starts at the current folder. From reports it asks for reports/data/seedlings.csv, not the neighbouring data folder. Return to the project root, then locate data/seedlings.csv. The file did not move; your starting location changed. In a shell, use pwd to identify that starting place.

3. Predict a pipe and a saved extract

The supplied samples.tsv has a header plus four records: two control and two treated. The header does not contain treated. What does this print, and does the second command change the source manifest?

grep -F treated samples.tsv | wc -l
grep -F treated samples.tsv > treated-samples.txt
Answer and check

The first command prints a line count of 2. grep sends matching lines through the pipe to wc. The second saves matches to treated-samples.txt; it does not change samples.tsv. > replaces any previous contents of the destination. This is literal text matching, not interpretation of treatment groups or chemical classes. It could also match untreated if that word occurred.

4. Copy, move, and extract

What remains after copying notes.txt to notes-copy.txt? How is moving the original different? Does opening a ZIP preview necessarily mean its files have been extracted into an ordinary project folder?

Answer and check

A copy leaves the original and makes another file. A move changes the original’s location or name. A ZIP preview is a view of an archive; use extraction to create the ordinary folder and files needed for the project. Locate the actual extracted .Rproj, rather than opening one inside an archive preview.

5. Memory and storage

Would adding RAM automatically provide more room for saved photographs? Why can restarting R remove objects while leaving a saved CSV intact?

Answer and check

RAM supports running work; persistent storage holds saved files. They have different roles. An R object in session memory must be recreated after restart; the CSV remains on storage and can be imported again. Saving a script preserves the instructions, not an automatically running process.

6. The same filename on two computers

You see report.html in a remote desktop. Is it automatically in your laptop’s Downloads folder? Would a ZIP stored beside the original be a separate backup against losing the laptop?

Answer and check

No to both. Remote access is not automatic file transfer, and identical names can refer to separate copies. Use the supported transfer route and name the destination. A ZIP on the same disk is a convenient sharing package; use supported separate storage for protection against losing that disk.

7. A renamed extension

A practice copy of seedlings.csv is renamed name-test.txt. Did its plant measurements become a different format? What would you inspect?

Worked answer

The name changed; renaming did not convert the contents. Open the practice copy as plain text and inspect its comma-separated header and records. Use actual conversion software only when a task calls for conversion; no conversion is needed here. Keep the original CSV unchanged.

8. Two terminal windows

Shell A is inside day03/readings while Shell B is in the workspace root. You run cd .. in Shell A. What changes in Shell B?

Worked answer

Nothing automatically changes in Shell B. Each shell has its own current directory. Check pwd in both windows. The folders themselves did not move, and changing a shell location does not move an independent file-manager window.

9. Quote the intended argument

You want one folder called field notes. Compare mkdir field notes with mkdir “field notes”. Which command expresses the intended single name?

Worked answer

The quoted command groups both words into one argument and creates one named folder. The unquoted command normally supplies two names and creates two folders. Practise only in the disposable workspace, then use ls and the graphical view to inspect what actually exists.

10. A surprising grep count

In a copy of the four-record manifest, S01 is labelled untreated; S03 and S04 are treated. How many records match grep -F treated, and does that count establish three treatment allocations?

Worked answer

There are three literal text matches because untreated contains treated. It does not establish three treated plants. Inspect the selected IDs and use the study description to understand labels. The unchanged source manifest still has two treated records.

11. A manifest path fails

The manifest lists measurements/S04.csv, but the copied folder contains S04-renamed.csv. Should you delete the record, change its measurement, or investigate identity?

Worked answer

Investigate. In the deliberate classroom rename, the file contents still identify S04 and 39.8 mm, and the known rename supports restoring its filename. In a real ambiguous case, obtain source evidence. Do not delete a record simply because a path fails.

12. The recipient has the old correction

You edited ordinary report/findings.txt after creating report-v1.zip. A partner extracts v1 and sees the old sentence. What happened, and what is a useful verification?

Worked answer

The archive is a snapshot and did not update when the source changed. Create a newly named package, extract it into a fresh receiver location, and inspect the actual corrected sentence. Confirm both archive version and extracted folder before assuming editing failed.
