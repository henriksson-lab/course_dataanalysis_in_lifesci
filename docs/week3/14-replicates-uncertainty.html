Day 14 — More readings are not always more independent evidence

Lecture slides · Quiz · Weekly revision

Today’s question

Would measuring the same plant ten times tell us as much about other plants as measuring ten different plants? The answer changes how we count evidence and interpret an average. Today is about experimental reasoning, supported by a supplied sampling simulation.

Identify what was independently sampled or treated

In the seedling experiment, plants are grown in separate pots and treatment is randomly assigned to plants. The plant is our independent experimental unit. An independent biological replicate provides another unit relevant to the question. A technical replicate repeats measurement of the same material, helping reveal measurement variation.

Three ruler readings of P01 can help assess how consistently it was measured. They do not turn it into three independently treated plants. Similarly, 100 cells from one organism are not automatically 100 independent organisms, and ten time points from one culture are not ten independent cultures. The unit follows the design and biological question, not the number of rows in a spreadsheet.

Imagine a nutrient treatment assigned to two trays, each holding twelve plants. If each tray receives a single shared treatment, the tray is a treatment unit. Treating all 24 plants as independently randomised units would overstate the independent treatment information. More data rows cannot repair that design.

Spread among plants versus uncertainty in a mean

SD describes how much measured plants vary. Sampling uncertainty concerns how our estimated mean would change if we repeated the sampling process. Even when a population’s spread stays the same, a mean based on more independent plants typically varies less from sample to sample.

Here is a teacher-provided demonstration. The clean seedling growth measurements serve as a fixed toy population for repeated sampling. This is not a new experiment and is not evidence about all plants in nature. Sampling with replacement is used to illustrate repeated draws from a fixed distribution.

Save the block in day14-sampling.R, then run it unchanged first:

library(readr)
library(dplyr)
library(ggplot2)
seedlings <- read_csv("data/seedlings.csv", show_col_types = FALSE) |>
  mutate(growth_mm = final_mm - initial_mm)
population_mm <- seedlings$growth_mm
set.seed(14)
means_4 <- replicate(400, mean(sample(population_mm, size = 4, replace = TRUE)))
means_16 <- replicate(400, mean(sample(population_mm, size = 16, replace = TRUE)))
sampling <- data.frame(mean_mm = c(means_4, means_16),
                       sample_size = rep(c("4 plants", "16 plants"), each = 400))
ggplot(sampling, aes(x = mean_mm)) +
  geom_histogram(binwidth = 1, colour = "white") +
  facet_wrap(~ sample_size, ncol = 1) +
  labs(x = "Mean growth in one simulated sample (mm)",
       y = "Number of simulated samples") +
  theme_minimal()
sd(population_mm)
sd(means_4)
sd(means_16)

sample() draws a sample; replicate() repeats the calculation 400 times. replace = TRUE allows a source value to be drawn more than once. set.seed() sets the starting state of the random-number generator so the demonstration can be repeated exactly. The resulting 400 means are summaries of simulated samples, not 400 newly measured plants.

Notice the horizontal axis: each value is a sample mean. Compare its spread between sample sizes. Do not confuse sd(means_16) with SD among the 16 plants inside one particular sample. The former describes variation among repeated estimates and approximates a standard error in this toy sampling process.

Compare sampling and study designs

  1. Before running the demonstration, predict which sample means will spread out more. Compare the plot and printed SDs with your prediction.
  2. Change the random seed to 25 and rerun. Exact bins change; does the main relationship between sample size and spread remain?
  3. Draw a small diagram for each design: twelve independent pots; one pot with twelve ruler readings; two trays with twelve plants each and tray-level treatment. Label the unit assigned to treatment. As an alternative to the one-pot diagram, draw one synthesis run whose collected product is weighed twelve times: there is one independently prepared run, not twelve. In the simulated organic dataset, six separately prepared runs were randomly assigned to each protocol; those runs provide independent protocol units.
  4. Complete this explanation for each design: “We have many measurements, but our number of independently treated units is …”.
  5. Explain the difference between SD among plants and uncertainty in a group mean for your report.
Hint: keep the sampling target fixed

Both means_4 and means_16 draw from the same population_mm. A larger sample does not alter those source values or their SD. It changes how much the repeated sample means vary. These combined-treatment values are only a teaching population; this simulation is not a treatment comparison.

Check your understanding

Is a precise mean enough?

No. Repeated measurements may be biased, dependent, or drawn from an unrepresentative source. A narrow sampling distribution does not establish that the sampling process answers the intended biological question. Independent units and an appropriate design still matter.

Count independent units in four designs

Save drawings or descriptions in output/day14-design-notes.txt and keep the sampling code in today’s script.

  1. Draw twelve separate pots, each with one plant, with nutrient allocation independently assigned to pots. Label the unit assigned to treatment, the measurement, and the number of independent units. Give the conditions under which it is reasonable to regard the pots as independent.
  2. Now draw one pot per treatment, with twelve ruler readings of its plant. Identify what variation those readings could help assess. Explain why the number of recorded lengths does not provide twelve independent treatment assignments.
  3. Draw two trays, each containing twelve plants, where treatment was applied to the whole tray. Identify which plants share a treatment unit and possible environment. State what independent replication is missing.
  4. Transfer the reasoning to either one culture measured at ten times, or one organic synthesis product weighed ten times. Name the biological or laboratory unit and the repeated measurements. Specify which question the repeats can inform and which comparison needs separately prepared units.
  5. Run the supplied sampling demonstration unchanged and save its histogram. Read the horizontal axis aloud: each value is a sample mean, not an individual plant. Make a small table containing SD among source values, SD among means from samples of four, and SD among means from samples of sixteen. Label what each row describes.
  6. Change only the random seed and rerun. Compare exact numerical results and the broad relationship. Then return to the stated seed. Explain why a reproducible simulation can use randomness, and why selecting a convenient seed is not evidence that one sampling method is generally better.
  7. Write a short response to: “The histogram is narrow, so the design must be good.” Identify assumptions about independence, sampling, and measurement that a narrow distribution of means cannot establish. Precision in a biased or irrelevant measurement is not a substitute for answering the question.
Hint: label the level at every stage

In this demonstration, population_mm is the fixed source vector. A single sample() call gives a group of draws. One mean() gives one estimate from that sample. replicate() collects many such estimates. Neither a hundred simulation runs nor ten technical readings creates additional measured plants. Keep the source SD and the SD of repeated means under different names.

Change sample size with a new source

Use the growth measurements from data/seedlings-transfer.csv as a new toy source distribution, not as proof about every plant. It combines allocations for this teaching demonstration; this is not a treatment comparison or a confidence interval for a treatment effect.

  1. Import and calculate growth from all 18 records. Document that one row is one measured independent plant in its source study, but repeated draws from this stored vector are simulated samples rather than new measurements.
  2. Adapt the supplied code to collect 400 means from samples of size three, then size twelve, with replacement, keeping the same source values. The changed setting is sample size. Predict which set of means will be more spread out before running it.
  3. Save both numerical vectors as columns of a derived table, or in a long table using the supplied data.frame() pattern. State that the 400 rows represent simulated estimates, not enrolled plants or independent protocols.
  4. Make comparable histograms or plots of the two distributions. Use shared axis limits and a stated bin width. Compare SD among means with SD among source observations. A larger sample size changes the estimate’s variation, not the original recorded plant values.
  5. Repeat with a second seed, retaining the first result as a separate object. Write a paragraph identifying a broad stable feature and an unstable exact value. Explain why the number of simulation repeats and number of plants per simulated sample are different settings with different meanings.
  6. End with a real design decision: if you could either measure each of two plants twenty more times or obtain ten additional independent plants, which option better informs a population mean, assuming comparable measurements? State the assumptions and also name a situation where checking measurement repeatability first would still be useful.

Additional outputs: four labelled design diagrams, a table distinguishing source spread from estimate spread, transfer simulation CSV/figure, and a interpretation of sample size, simulation repeats, and independent units.
